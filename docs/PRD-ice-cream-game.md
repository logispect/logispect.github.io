## 1. 背景与目标

做一个给小朋友玩的本地小游戏。孩子用点按完成一份冰淇淋，看到成品，再做下一份。

本期只做冰淇淋。做饭（三明治、水果盘）用同一套「选材料 → 叠上去 → 开心收尾」的流程，放到下一期，避免第一版步骤变多。

**目标**

- 不识字也能玩完：图标大、颜色分明、语音说下一步。
- 一次只做一件事，一份冰淇淋大约 1 分钟。
- 没有失败、没有倒计时、没有扣分。点错了轻轻提示，不打断。
- 全部在浏览器本地运行，不注册、不上传。

**非目标（本期不做）**

- 做饭、烘焙等其它厨房主题
- 积分排行、连击、限时挑战
- 账号、存档云同步、社交分享
- 广告、外链、应用内购买
- 需要精细拖拽、双指缩放、长按的操作

---

## 2. 用户与场景

| 角色 | 说明 |
|------|------|
| 小朋友（约 5 岁） | 会点屏幕上的大按钮；识字不稳定；注意力大约几分钟 |
| 家长 | 打开页面、调音量、需要时点「再来一份」或「回家」 |

**典型场景**

家长打开游戏 → 语音说「先选一个杯子」→ 孩子点甜筒或杯子 → 点一个口味 → 点一个配料 → 看冰淇淋叠好、小动物开心 → 点「再做一份」。

---

## 3. 一局怎么玩

固定 4 步，不能跳步，也不能同时出现两步的选择。

| 步骤 | 孩子做什么 | 画面 |
|------|------------|------|
| 1. 选容器 | 点甜筒或杯子（二选一） | 容器出现在画面中间 |
| 2. 选口味 | 点 1 个口味球 | 球叠到容器上，轻轻晃一下 |
| 3. 选配料 | 点 1 个配料 | 配料落在球上面 |
| 4. 完成 | 不用再选 | 成品放大，小动物笑，语音「做好啦」 |

完成后只出现两个大按钮：

- **再做一份**：回到第 1 步，容器清空
- **看一看**：成品停留，方便家长和孩子一起看（点画面任意处或「再做一份」离开）

中途可点 **返回上一步**（只退一步，已选的更早步骤保留）和 **重来**（清空，回到第 1 步）。

## 4. 功能需求

### 4.1 材料（数量要少）

| ID | 需求 | 优先级 |
|----|------|--------|
| F-01 | 容器 2 个：甜筒、杯子 | P0 |
| F-02 | 口味 4 个：草莓（粉）、巧克力（棕）、香草（白）、芒果（黄）。每个是一颗圆球 + 颜色，不依赖文字 | P0 |
| F-03 | 配料 4 个：樱桃、巧克力酱、彩虹糖、空白「不加了」 | P0 |
| F-04 | 每步只选 1 个。选中后立刻进入下一步 | P0 |
| F-05 | 选中项有明显反馈：放大一点、描边、短音效 | P0 |

### 4.2 步骤与流程

| ID | 需求 | 优先级 |
|----|------|--------|
| F-10 | 始终只显示当前这一步的选项。其它步骤的选项先不出现 | P0 |
| F-11 | 顶部用 4 个圆点表示进度。当前步高亮，已完成的点亮，未到的变淡 | P0 |
| F-12 | 「返回上一步」退回上一步，并撤销这一步刚选的东西 | P0 |
| F-13 | 第 1 步不显示「返回上一步」 | P0 |
| F-14 | 「重来」清空成品，回到第 1 步 | P0 |
| F-15 | 第 4 步自动播放完成，不需要孩子再点「完成」 | P0 |

### 4.3 完成与再来

| ID | 需求 | 优先级 |
|----|------|--------|
| F-20 | 完成后展示完整冰淇淋（容器 + 球 + 配料） | P0 |
| F-21 | 出现一个固定的小动物顾客（例如小熊），表情从期待变成开心 | P0 |
| F-22 | 「再做一份」一局结束后即可点，按钮是画面上最大的操作之一 | P0 |
| F-23 | 连续玩不累计失败，也不弹出「你赢了 / 你输了」 | P0 |

### 4.4 语音与声音

| ID | 需求 | 优先级 |
|----|------|--------|
| F-30 | 每步开始有一句短语音，例如「选一个杯子」「选一个口味」「选一个配料」「做好啦」 | P0 |
| F-31 | 点选有轻快音效；完成有稍长一点的开心音效 | P0 |
| F-32 | 页面上有「声音」开关，默认开。关掉后语音和音效都停，玩法不变 | P0 |
| F-33 | 家长首次点击页面后才出声（遵守浏览器自动播放限制） | P0 |
| F-34 | 语音用普通话，语速偏慢，一句不超过 6 个字 | P0 |

语音可以用预录短音频。若首版没有录音，用浏览器语音合成（`speechSynthesis`，中文）顶上，句子仍保持很短。

### 4.5 家长向的界面

| ID | 需求 | 优先级 |
|----|------|--------|
| F-40 | 左上角「回家」回到站点首页，热区要大，避免和游戏按钮贴在一起 | P0 |
| F-41 | 不出现小字说明墙、不出现需要阅读的教程 | P0 |
| F-42 | 名字可以显示在标题，但是玩的过程不靠文字。按钮用图标：返回、重来、声音、再来一份 | P0 |

## 5. 交互与适龄

| ID | 需求 | 优先级 |
|----|------|--------|
| U-01 | 可点的东西最小约 64×64 像素，材料按钮建议更大（接近 96 像素） | P0 |
| U-02 | 操作只有点按。不要求拖拽对准 | P0 |
| U-03 | 点到空白处没有惩罚，也不弹错误 | P0 |
| U-04 | 动画短：单次不超过 1 秒。完成庆祝可以到 2 秒 | P0 |
| U-05 | 手机竖屏优先，平板横屏也能玩。选项不要挤出屏幕，需要时可横滑，但一次尽量不用滑 | P0 |
| U-06 | 颜色对比清楚。不只用颜色区分：甜筒和杯子形状不同，配料形状不同 | P0 |
| U-07 | 支持键盘无障碍不是本期重点；要保证按钮有可读名称，方便读屏家长 | P1 |

## 6. 画面结构

一屏完成，不换页。

```
[ 回家 ]                         [ 声音 ]
[ 进度：● ● ○ ○ ]

           （中间：正在做的冰淇淋）

[ 当前这步的 2～4 个大选项 ]

[ 返回上一步 ]              [ 重来 ]
```

完成后，中间换成成品 + 小动物，底部变成「再做一份」。

视觉和现有工具站的石墨绿可以不同：这页用浅奶油底、草莓粉和芒果黄，字仍然要少。材料用扁平色块图，不需要写实照片。

## 7. 安全与隐私

| ID | 需求 | 优先级 |
|----|------|--------|
| S-01 | 不收集姓名、年龄、照片、语音录音 | P0 |
| S-02 | 不请求摄像头、麦克风、定位 | P0 |
| S-03 | 游戏页不放广告、不跳出第三方页面 | P0 |
| S-04 | 不展示刀具、明火、插座等需要模仿的危险动作。冰淇淋只用「选好就叠上去」 | P0 |
| S-05 | 声音开关和回家按钮在家长伸手可及的位置，不藏在多层菜单里 | P0 |

---

## 8. 验收

- 不识字的孩子在家长不讲解步骤的情况下，能靠语音和图标做完至少 1 份冰淇淋。
- 从打开到看到「做好啦」，点按次数不超过 5 次（容器、口味、配料，加上结束后的「再做一份」）。
- 全程没有失败提示、没有倒计时。
- 关掉声音后仍能靠画面做完。
- 刷新页面后从第 1 步开始，不残留上一份。
- 手机竖屏上，材料按钮不会小到要点很多次才点中。
